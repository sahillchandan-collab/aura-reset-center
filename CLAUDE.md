# Repository notes

## Botany Properties brand assets

The company stamp, logo and letterhead artwork for Botany Properties L.L.C live in `botany-letterhead/assets/`. Use `botany-letterhead/build-letter.js` to put any new letter on the letterhead, and place the stamp from `assets/botany-stamp-for-documents.png` in clear space beside the sign-off, never over text. See `botany-letterhead/README.md`.
